Vice Sunset Studio — turn a photo and a caption into GTA 6-style cover art, exported as a PNG. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — load a photo, arrange the panels, edit the caption, export a PNG.
